# Architecture Decision Records

One file per important decision: `NNNN-short-title.md`, numbered in order. An accepted ADR is not rewritten; a new one supersedes it. The About page is based on these records, rewritten for visitors.

## Template

```markdown
# NNNN. Title

Date: YYYY-MM-DD
Status: Proposed | Accepted | Superseded by NNNN

## Context
What forces the decision, including the hardware limits.

## Decision
What we do, in one or two sentences.

## Trade-offs
- Pro:
- Con:

## Alternatives considered
- Option: why not.
```
